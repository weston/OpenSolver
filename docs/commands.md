# UPI command compatibility and coverage

Inventory of the public [UPI 3.10 command list](https://piosolver.com/docs/upi/commands/)
and every command registered in `src/upi*.cpp`, including parser-level commands and
the two removed-command errors. Reviewed against this repository's implementation,
[known differences](../README.md#known-differences-from-piosolver),
[verified Pio observations](../AGENTS.md#verified-pio-behavior-3101-that-the-docs-dont-state),
and tests. This is a compatibility/evidence index, not a promise that every argument
and error path has been compared with Pio.

## Reading the table

- **Exact**: byte-for-byte comparison against captured Pio category output.
- **Semantic**: the behavior described in the notes is supported by the repository's
  verified Pio observations. Numeric results can differ by rounding or convergence;
  this does not claim exact output for every input.
- **Differs**: a known difference or an implementation-specific setting/format.
- **Unverified**: implemented, but no recorded equivalence claim is made here.
- **Probed**: run black-box against PioSOLVER 3.10.1 with `tests/pio_compare/compare.py` (local Pio,
  2026-11-04, main `9c907a4` plus #247's and probe 11's fixes) in the probes listed, and every response was
  byte-identical. That is evidence for those inputs, not for every argument and error path. Probes 17-25 were run
  the same way on 2026-11-07 (main of that day), probe 25 on 2026-11-12: a row marked Probed from them cites the probe.
- **Removed**: recognized only to return an explicit UPI 3.10 removal error.

`UPI` links locate command references in the end-to-end regression test; some are
setup or helper calls rather than dedicated assertions. `probeN` links are inputs
for black-box Pio comparison, **not evidence that a comparison was run or passed**.
`Categories` is the byte-exact recorded-output regression. A dash means no direct
command reference was found in those tests/probes, not that the command is absent.
The source link on each command is the implementation authority for its arguments.

Default builds omit hands that occur only in the opponent's range. Set
`set_union_hands on` before building for Pio-style hand lists. This affects EV and
pretty-printed listings. Saves are this solver's own format and cannot be exchanged
with PioSOLVER even though the UPI command names are shared. Exact preflop equity
comes from our own generated table; the first use can be expensive.
